# Known Issues & Troubleshooting: skill-web-collection

## 既知の問題と対策

### ヘッドレス実行におけるプロジェクト外パスアクセス制限と対策
- **発生日**: 2026-11-15（Issue #4 検証時）
- **症状**: ヘッドレス実行環境（`opencode run` 等）において、プロジェクト外ディレクトリ（例: `/tmp/*` や `~/workspace/my-docs/*`）にツール（Read / Bash / Grep 等）で直接アクセスしようとすると、セキュリティ機構により自動却下され、セッション自体が強制終了する。
- **原因**: 外部ディレクトリへのセキュリティ制約（`external_directory` 拒否）。
- **対策**:
  1. すべての検証成果物や一時ファイル、参照テンプレートのコピーは必ずプロジェクト内（例: `.verify-issue4/` やプロジェクト内の `references/` 等）に配置し、プロジェクト外ディレクトリを直接参照・出力しないこと。
  2. ただし、ラッパースクリプトの子プロセス（`agy` コマンド等）が内部でプロジェクト外のプロファイルやテンプレートパスを参照するのはツールのアクセス禁止対象外となるためそのまま実行可能。ただしラッパーが指定する出力先は必ずプロジェクト内に収める。
