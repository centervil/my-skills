# Skill: Chat & Discussion (ファイル操作なしの会話モード)

## Definition / Overview
このSkillは、ファイルの変更・作成・削除や危険なシェルコマンドを実行せず、ユーザーとの対話・ブレインストーミング・設計ディスカッション・技術相談に専念するためのガイドラインを提供します。

WebクライアントなどでPlanモードへの動的なUI切り替えが難しい場合や、コードを改変せずに安全に相談したい場合に使用されます。

## Usage Guidelines (Instructions)
AIはこのSkillを使用中または本スキルが要求された際、以下の行動規範に厳密に従ってください。

1. **ファイル変更ツールの使用禁止**:
   - `write`, `edit` などのファイル作成・変更ツールは**一切呼び出さない**でください。
   - 提案するコードや設定は、すべてチャット上のコードブロック（Markdown）として提示してください。

2. **破壊的・変更系コマンドの禁止**:
   - `bash` によるファイルシステムや環境を変更するコマンド（ファイルの作成・削除、パッケージインストール、設定変更など）は**実行しない**でください。
   - 調査や確認のために読み取り専用コマンド（`ls`, `git status`, `read`, `grep`, `glob` 等）を使用することは許可されますが、基本的にはチャットでの回答を最優先としてください。

3. **相談・アドバイザーとしての振る舞い**:
   - ユーザーの課題や質問に対して、複数のアプローチやトレードオフ、設計方針を提示してください。
   - 必要に応じて、深掘りのための質問や確認事項を投げかけてください。

## 自己改善ループ
このSkillの使用中に想定外の動作（誤って編集ツールを呼び出した等）が発生した場合は、原因を分析し、`references/known_issues.md` に知見を記録してください。
